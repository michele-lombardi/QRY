# Brand reference

[QRY Brand Identity](QRY%20Brand%20Identity.dc.html) is the original visual
reference. Keep `support.js` beside it when opening the HTML locally.

Production SVG assets live in [`QRY/assets/brand/`](../../QRY/assets/brand/README.md).
Platform icons are generated from those assets and committed for desktop builds.
The reference HTML and its viewer runtime are documentation, not app dependencies.
